# VI Engine

> **Vertical Intelligence Engine** — an automated newsletter pipeline that discovers, filters, and publishes industry-specific content with an opinionated editorial voice.

VI Engine monitors news sources across multiple industries, lets you review and approve articles from a local dashboard, generates AI-written newsletters using a layered skills system, and publishes directly to X (Twitter), Ghost, and WordPress.

---

## What it does

```
Collect → Review → Generate → Publish
```

| Stage | What happens |
|-------|-------------|
| **Collect** | Pulls articles from Hacker News, RSS feeds, and Google News for each configured pipeline (e.g. Tech/AI, Oil & Gas) |
| **Review** | Split-panel dashboard — article list on the left, live webpage preview on the right. Approve or discard with one click |
| **Generate** | Claude synthesises approved articles into a newsletter using a composable skills system (voice + industry + platform) |
| **Publish** | One-click push to X as a thread, Ghost CMS, or WordPress. LinkedIn preview generated for manual posting |

## Skills system

Content is generated by composing layered skill files:

```
base/voice.md          ← universal anti-slop writing rules (always included)
    +
voices/skeptical_analyst.md   ← "compared to what?" — benchmark everything
voices/pragmatic_operator.md  ← implementation reality, cost to deploy
voices/contrarian.md          ← attack the load-bearing assumption
voices/enthusiastic.md        ← early signal, adoption curve focus
voices/policy_wonk.md         ← specific agencies, compliance costs
    +
industries/oil_gas_energy.md  ← upstream/midstream/downstream vocabulary
industries/tech.md            ← LLM/RAG/GPU, AI hype vs reality
industries/fintech.md         ← AML/KYC/BaaS, regulatory tensions
industries/edtech.md          ← LMS/MOOC/FERPA, outcomes vs engagement
    +
platforms/blog.md             ← 800–1500 words, SEO structure
platforms/linkedin.md         ← 900–1300 chars, hook line, 2 hashtags max
platforms/twitter.md          ← 5–8 tweet thread, `---` separated, no fluff
```

Each newsletter has a user-selected voice and industry. Platform content is generated on-demand for each output format.

## Pipelines

Named pipelines are defined in [`pipelines.json`](pipelines.json) at the project root. Each pipeline has its own RSS feeds, Google News queries, and industry tag.

```json
{
  "pipelines": [
    {
      "slug": "tech_ai",
      "label": "Tech & AI",
      "industry": "tech",
      "include_hn": true,
      "include_ai_blogs": true,
      "rss_feeds": ["..."],
      "google_news_queries": ["LLM release", "AI regulation", "..."]
    },
    {
      "slug": "oil_gas",
      "label": "Oil & Gas / Energy",
      "industry": "oil_gas_energy",
      "include_hn": false,
      "rss_feeds": ["https://jpt.spe.org/rss/recent-articles", "..."],
      "google_news_queries": ["microseismic processing", "completion optimization", "..."]
    }
  ]
}
```

Add a new pipeline by adding a block to `pipelines.json` — no code changes required.

## Setup

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Configure environment

Copy `.env.example` to `.env` and fill in your keys:

```bash
cp .env.example .env
```

```env
# Required
ANTHROPIC_API_KEY=sk-ant-...

# X (Twitter) — developer.twitter.com → Keys and Tokens
X_API_KEY=...
X_API_SECRET=...
X_ACCESS_TOKEN=...
X_ACCESS_TOKEN_SECRET=...

# Optional — Ghost CMS
GHOST_ADMIN_URL=https://your-blog.ghost.io
GHOST_ADMIN_API_KEY=key_id:hex_secret

# Optional — WordPress
WORDPRESS_SITE_URL=https://your-blog.com
WORDPRESS_USERNAME=...
WORDPRESS_APP_PASSWORD=...

# Pipeline / domain label
VI_DOMAIN_TAG=your-newsletter-name
```

### 3. Run the dashboard

```bash
python -m uvicorn vi_engine.dashboard.app:app --reload --port 8000
```

Open [http://localhost:8000](http://localhost:8000).

### 4. Collect articles

Click **Run Collection** in the dashboard, or from the CLI:

```bash
python -m vi_engine.collect_candidates
```

## Project structure

```
vi_engine/
├── collect_candidates.py   # Phase 1 — fetch articles from all pipelines
├── config.py               # Central settings (env vars)
├── pipeline_config.py      # Loads pipelines.json
├── categorize.py           # Keyword + LLM category classification
├── extract.py              # Content extraction, structural junk filtering
├── llm.py                  # Anthropic wrappers — filter, synthesise, generate
├── state.py                # SQLite ORM — candidates, newsletters, targets
├── dashboard/
│   ├── app.py              # FastAPI routes
│   └── templates/          # Jinja2 HTML templates
├── publishers/
│   ├── ghost.py            # Ghost CMS publisher
│   ├── wordpress.py        # WordPress publisher
│   └── twitter.py          # X thread publisher
├── skills/
│   ├── base/voice.md       # Universal writing rules
│   ├── voices/             # Editorial voice skill files
│   ├── industries/         # Industry vocabulary skill files
│   └── platforms/          # Platform format skill files
└── sources/
    ├── hacker_news.py
    └── google_news.py

pipelines.json              # Pipeline definitions (edit to add streams)
tests/                      # 110 pytest tests
Dockerfile
docker-compose.yml
```
